# 扶握箱時間軸第二批：操作便利

分類：規劃與進度 · [文件總覽](../README.md)

狀態：**第二批已實作**。本文保留操作、介面、資料規則與驗收規格；實際成果與驗證範圍見 [實作與驗測報告](../development/grab-timeline-usability-report.md)，操作說明見 [扶握箱時間軸](../features/grab-timeline.md)。

## 1. 目標與現況

讓使用者能在扶握箱面板內連續記錄動作，並在時間軸上看懂每個拍點的扶握狀態與放手位置。

| 項目 | 現況 | 第二批工作 |
| --- | --- | --- |
| 新增／更新拍點 | 已記錄角色與扶握箱，按鈕在時間軸 | 在扶握箱面板提供快捷操作 |
| 選取與播放 | 已還原扶握設定，支援停止保持姿勢與尋位 | 清楚區分編輯拍點與播放頭位置 |
| 拍點顯示 | 以 F1／F2、備註與轉場資訊為主 | 增加扶握資料標記與狀態摘要 |
| 扶握／放手 | 已在拍點邊界切換 | 顯示左右手狀態與相鄰拍點的變化 |
| 單拍複製 | 已保留扶握資料，第一批已有驗證 | 補上標記更新與複製後獨立編輯驗證 |
| 多選／Range | 共用完整項目的深拷貝流程 | 補上含扶握資料、混合舊拍點及邊界的驗證 |

沿用現有 POSE 軌道與 `keyframes[].grabBox.version: 1`。第二批新增介面與回歸驗證，專案 schemaVersion 維持 1；尺寸連續變形、接觸點滑動、平滑抓取／放手與獨立箱子軌道屬後續進階規劃。

## 2. 扶握箱面板的時間軸快捷區

建議放在一鍵擺位與重設操作之後、詳細形狀設定之前，手機也能快速找到。

| 操作 | 行為 | 完成提示 |
| --- | --- | --- |
| ＋新增拍點 | 記錄目前角色姿勢、身體與扶握箱狀態；沿用拍數與 Easing 預設 | 已新增 F3：雙手扶握 |
| 更新 F2 | 覆寫目前選取拍點的角色姿勢、身體與扶握箱；保留備註、拍數、Easing 與其他 metadata | 已更新 F2：右手扶握 |
| 查看時間軸 | 切換時間軸分頁，將選取拍點捲到可見位置；沒有選取時顯示時間軸 | 不改變場景或拍點資料 |

「更新」是更新整個姿勢拍點，包含角色與箱子。按鈕附近用簡短文字說明，避免使用者以為只更新箱子。

新增位置沿用現有規則：有有效單選拍點時插在其後，沒有選取時加到末尾。新增後選取新拍點；更新後保留原選取。每次新增或更新只形成一個 Undo 步驟，並排程自動存檔。

### 啟用條件

| 情況 | 新增 | 更新 | 查看時間軸 |
| --- | --- | --- | --- |
| 模型就緒、單選 F2 | 可用 | 可用，顯示「更新 F2」 | 可用 |
| 沒有選取 POSE | 可用，新增至末尾 | 停用，提示先選取拍點 | 可用 |
| POSE 多選模式 | 停用 | 停用，提示切回單選 | 可用 |
| 播放中 | 停用 | 停用，提示先停止播放 | 可用 |
| 模型尚未就緒 | 停用 | 停用 | 可用 |
| 正在拖曳箱子或調整尺寸 | 手勢結束後可用 | 手勢結束後可用 | 可用 |

形狀隱藏或雙手已放開時仍可記錄拍點，才能編排「放手／隱藏」動作。停用原因顯示在快捷區內，手機不依賴滑鼠提示。

## 3. 編輯目標與尚未寫入的調整

快捷區分開顯示兩種資訊：

- **編輯目標**：例如「目前選取：F2」，決定更新按鈕的寫入對象。
- **場景狀態**：例如「箱子已顯示・雙手扶握・掌面貼合」，描述畫面中的即時狀態。

拖動播放頭只是在預覽動畫，不能默認把該位置當作更新目標。第二批建議在尋位後停用「更新」，提示「預覽中，請重新選取拍點後更新」；「新增」仍可將停止狀態下的預覽姿勢記錄成新拍點，插入位置明示為保留的選取拍點之後或末尾。

選取拍點後，以可儲存的角色姿勢、身體與扶握資料作為比較基準。完成箱子拖曳、尺寸／朝向／扶握調整或角色編輯後，若資料不同，顯示「目前調整尚未寫入 F2」。相機、語言與分頁切換不列入姿勢變更。

新增／更新後清除該提示；重新選取、匯入與 Undo／Redo 後重新建立基準。採非阻擋式提示，不加入每次切換都要確認的對話框。自動存檔保存工作區與時間軸，也不代表工作區調整已覆寫選取拍點。

## 4. 拍點標記與狀態摘要

有有效 `grabBox` 資料的拍點顯示小型「扶握」標記；詳細狀態放在選取摘要與可讀名稱中，避免短拍長時標記擠滿卡片。

| 儲存狀態 | 摘要文字 |
| --- | --- |
| 顯示形狀且左右手啟用 | 雙手扶握 |
| 顯示形狀且只有右手啟用 | 右手扶握 |
| 顯示形狀且只有左手啟用 | 左手扶握 |
| 顯示形狀且雙手皆未啟用 | 形狀已顯示・未扶握 |
| 有資料但形狀隱藏 | 形狀已隱藏 |
| 沒有扶握資料的舊拍點 | 無扶握資料 |

隱藏形狀的拍點仍有資料標記，與完全沒有資料的舊拍點分開顯示。「扶握」標記代表含扶握箱設定，不代表該拍點一定有手扶住形狀。

詳細摘要提供形狀、左右手、掌面貼合開關與手腕角度。桌面可使用 Tooltip；手機在選取區直接閱讀。標記以文字／圖示共同表達，並提供繁中／英文與 aria-label；不只靠顏色辨認，也不攔截原本的點選、排序與調長手勢。

## 5. 扶握／放手的變化提示

依時間軸中相鄰拍點的有效扶握狀態比較，顯示事件發生在目前拍點：

| 前一拍 → 目前拍 | 變化提示 |
| --- | --- |
| 雙手扶握 → 只剩左手 | 右手放手 |
| 只有左手 → 雙手扶握 | 右手開始扶握 |
| 雙手扶握 → 雙手皆未扶握 | 雙手放手 |
| 未扶握 → 雙手扶握 | 雙手開始扶握 |
| 左手扶握 → 右手扶握 | 左手放手・右手開始扶握 |
| 形狀顯示 → 隱藏 | 形狀隱藏；若前一拍有扶握，同時顯示放手 |
| 扶握狀態相同，只有位置改變 | 顯示狀態摘要，不標示抓取／放手事件 |

第一拍顯示初始狀態，不推定有前一拍。混合時間軸中的缺少資料拍點，依第一批規則視為沒有箱子與扶握；全部沒有資料的舊時間軸維持一般姿勢顯示。

這些提示由拍點資料即時計算，不存入 JSON。複製、排序、貼上、刪除或更新拍點後，依新的前後關係重新計算，避免留下錯誤的「放手」標記。提示不更改第一批的拍點邊界切換時機。

## 6. 複製、多選與範圍編輯

沿用完整項目的深拷貝流程，重點是補足扶握資料的驗證與操作回饋。

| 操作 | 第二批要求 |
| --- | --- |
| 單拍複製 | 保留角度、身體、扶握資料、備註及轉場設定；修改副本不影響原拍點 |
| 多選複製／貼上 | 保留原順序及各自資料，含扶握與無資料拍點可混合貼上 |
| 剪下／刪除 | 不留下與拍點脫離的扶握資料，更新選取與相鄰變化提示 |
| Range 複製／重複 | 延續完整轉場與端點語意，保留端點的扶握狀態 |
| 排序／前移／後移 | 扶握資料隨拍點移動，重新計算開始扶握與放手提示 |
| Undo／Redo | 一次操作整組還原；資料、數量、選取及摘要保持一致 |

Range 邊界落在轉場中間時，沿用現有完整項目規則，不新增半段箱子動畫。貼上位置也沿用完整項目之後的規則。貼入新鄰接關係後，轉場會由新相鄰拍點決定，不能宣稱貼上後的跨接動作一定與來源相同。

操作回饋可顯示「已複製 3 個 POSE，其中 2 個含扶握資料」。數量按實際複製的姿勢拍點計算；Range 同時包含端點時，拍點數與轉場數須分開標示。只有剪貼簿複製不變更編舞；貼上、剪下、刪除與排序需支援 Undo／Redo 與自動存檔。

## 7. 手機、浮動面板與語言

- 快捷按鈕點選區至少 44px，小螢幕可換行；300px 浮動面板也能操作。
- 保留主面板既有橫向分頁與獨立內容捲動，快捷區不建立額外固定覆蓋層。
- 尋位、水平捲動與排序按鈕遵守既有觸控編輯模式，標記不搶取 pointer 手勢。
- 所有新增文字支援繁中／英文；切換語言保留輸入節點、選取、草稿提示與目前扶握狀態。
- 新增／更新成功透過非阻擋式狀態文字回饋；播放時不逐幀朗讀狀態。

## 8. 建議實作順序與模組分工

| 順序 | 工作 | 主要位置 |
| --- | --- | --- |
| 2A | 快捷區、編輯目標、按鈕啟用條件與單次歷史操作 | `src/ui/grab-panel.js`、`src/timeline/pose-editor.js`、共用操作 adapter |
| 2B | 拍點標記、狀態摘要、相鄰變化與尚未寫入提示 | `src/ui/timeline-editor.js`、`src/ui/timeline-inspector.js`、獨立狀態摘要 helper |
| 2C | 複製／多選／Range 邊界驗證與回饋 | `src/timeline/selection-clipboard.js`、`src/timeline/range-editor.js`、現有歷史與儲存流程 |
| 2D | 手機／浮動面板／語言回歸、圖文手冊更新 | `styles/simulator.css`、i18n、瀏覽器測試與 `docs/features/` |

快捷區呼叫共用編輯操作，不複製一套新增／更新邏輯。資料摘要與相鄰事件使用純函式；編輯草稿比較與預覽狀態獨立管理。`main.js` 保留接線，UI 不直接操作箱子 mesh 或改寫 keyframes。

## 9. 驗收清單

以下保留驗收規格；各項實際驗證方式、結果與限制，以 [驗測報告](../development/grab-timeline-usability-report.md) 為準。

| 案例 | 預期結果 |
| --- | --- |
| 在扶握箱連續記錄「扶握 → 搬高 → 旋轉 → 放手」 | 四個拍點可直接新增，播放沿用第一批行為 |
| 更新 F2，且 F2 有備註／拍數／Easing | 只更新姿勢與扶握設定，其他資料保留；一次 Undo 可還原 |
| 無選取／多選／播放／拖曳中 | 啟用條件符合表格，停用操作不改資料或歷史 |
| 選取 F2 後預覽 F3 附近 | 不會誤將預覽直接覆寫 F2；重新選取後可更新 |
| 移動箱子、旋轉手腕與改變角色姿勢 | 顯示尚未寫入提示；相機與語言切換不誤判 |
| 雙手、單手、未扶握、隱藏與無資料拍點 | 標記與摘要正確，角色姿勢與 box 狀態一致 |
| Back／Elastic 與放手拍點 | 提示指向拍點邊界，播放仍不提前放手 |
| 複製後修改尺寸／接觸點／手腕角度 | 原拍點與剪貼簿資料不被副本修改 |
| 混合舊拍點、多選貼上、Range 涵蓋放手端點 | 資料與端點完整，貼上後依新鄰接關係更新提示 |
| 刪除、排序、範圍重複與 Undo／Redo | 整組還原，選取、摘要、標記與存檔一致 |
| JSON 匯出／匯入、自動存檔重載 | 仍相容第一批格式，草稿提示與衍生標記不寫入專案 |
| 原始／打包版，桌面、320／390px、橫向與 300px 浮動面板 | 無頁面溢出，按鈕可點，標記不破壞拖曳與捲動 |
| 繁中／英文切換 | 文字與可讀名稱完整，選取及扶握設定保留 |
