# 場景與畫質（第一批）

[文件總覽](../README.md)

開啟「場景與畫質」分頁，可調整背景色、地面網格顯示及兩種線色、霧效、環境光顏色與亮度、主光亮度、輪廓光開關／顏色／亮度。亮度滑桿顯示數值；拖動一次形成一次 Undo／Redo 操作。

提供原始風格、中性練習、明亮背景三種預設，以及「恢復原始外觀」。中性及明亮預設採用白色環境光並關閉粉紅輪廓光。霧的顏色跟隨背景；明亮背景使用深色面板及較深的關節球／骨架線，維持辨識度。這不是完整的介面亮色主題。

## 人偶顏色與材質

在同一分頁的「人偶顏色與材質」區塊，選擇原始、霧面、亮面塑膠、金屬或自訂材質，並調整全身統一顏色、粗糙度與金屬感。

| 選項 | 粗糙度 | 金屬感 |
| --- | --- | --- |
| 霧面 | 0.95 | 0 |
| 亮面塑膠 | 0.22 | 0 |
| 金屬 | 0.30 | 0.75 |

調整粗糙度或金屬感會切換為自訂材質；從原始模式選顏色會啟用霧面外觀。數值範圍為 0～1。金屬呈現受燈光影響，本批沒有加入 HDR 環境反射。

「恢復原始人偶」還原模型原始材質與貼圖，保留背景、燈光與清晰度。「恢復原始外觀」則重設整個專案外觀。切換背景／燈光預設不會清掉已選的人偶材質。

自訂材質使用獨立複本，不修改原始材質、骨架、幾何或洋蔥皮。顏色為全身統一配色，尚未提供身體部位分色、貼圖上傳或透明材質。

人偶設定存於 `appearance` 的 `modelStyle`、`modelColor`、`modelRoughness`、`modelMetalness`，沿用專案保存、自動存檔與 Undo／Redo。舊專案缺少這些欄位時使用原始材質；新材質也不逐拍記錄在時間軸。

## 保存

- 外觀以 `appearance.version:1` 隨專案與歷史保存，不寫進每個拍點。
- 只有外觀變更、尚未建立拍點時，仍可使用時間軸的匯入／匯出，也可自動存檔還原。
- 舊專案缺少外觀欄位時，還原原始風格。
- 清晰度以 `tuttingRenderQuality` 保存在裝置的瀏覽器偏好，不隨專案或 Undo／Redo 改變。

## 清晰度

| 選項 | 主畫面像素比例上限 | 分割視窗上限 |
| --- | --- | --- |
| 省電 | 1 | 1 |
| 標準 | 1.5 | 1.5 |
| 清晰（預設） | 2 | 1.5 |

實際比例另受裝置 `devicePixelRatio` 限制。選項影響渲染解析度，並不保證 FPS，也不改動抗鋸齒、姿勢、IK 或時間軸。

本批不含漸層、背景圖片、地面陰影、發光後製、透明圖片匯出或逐拍外觀動畫。尚未進行手機實機效能驗證。
