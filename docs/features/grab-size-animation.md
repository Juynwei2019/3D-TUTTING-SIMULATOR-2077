# 扶握箱時間軸第三批 3A：尺寸連續變化

分類：功能說明 · [文件總覽](../README.md)

同一形狀可以在兩個拍點之間逐漸放大或縮小，扶握中的手掌隨表面尺寸移動。此批完成第三批的 **3A**；接觸點滑動與平滑扶握／放手仍是後續 3B／3C。

## 操作

1. 開啟扶握箱，選長方體、球體或圓柱，安排雙手接觸。
2. 勾選 **平順改變尺寸（至下一拍）**，新增起始拍點。
3. 調整尺寸，再新增下一個拍點。
4. 設定起始拍點的拍數與 Easing，播放或尋位預覽尺寸變化。
5. 修改既有轉場時，先選取起始拍點，勾選／取消此選項，再按 **更新 F…**。

選項屬於起始拍點，決定它到下一拍的尺寸動畫；最後一拍沒有下一段。工作區勾選不會自動覆寫已記錄拍點。可以先取消選項再記錄，保留逐拍切換。勾選本身、拍點更新及尺寸調整均沿用 Undo／Redo 與自動存檔。

## 動畫規則

- 長方體插值寬、高、深；球體插值半徑；圓柱插值半徑與高度。
- 只有兩端有效且同形狀、起始拍點開啟選項時才連續變化。
- 沿用起始拍點的 Easing，但尺寸用於插值的值限制於 0～1，避免 Back／Elastic 造成非法尺寸。位置與旋轉保留原本的緩動行為。
- 手掌保留起始表面的相對接觸位置，隨尺寸縮放；這不是沿表面滑動的 3B 功能。
- 下一拍的接觸點、形狀、扶握與隱藏仍在拍點邊界切換。兩端接觸配置不同時，邊界可能出現變化。
- 超過手臂可達範圍時仍受實際骨架限制，尺寸動畫不保證任意大形狀都能接觸。
- 舊專案缺少選項時採逐拍切換。選用欄位為 `sizeTween: true`，資料版本仍為 1。
